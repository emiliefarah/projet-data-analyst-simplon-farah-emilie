# Projet de positionnement - Formation Data Analyst Simplon
## Présentation
Ce projet a été réalisé dans le cadre du positionnement pour intégrer la Formation Data Analyst Simplon.
L'objectif est d'analyser un jeu de données de ventes à l'aide de SQL, puis de réaliser des visualisations avec Python,Pandas et Plotly.

## Technologies utilisées
- SQL
- Python
- Pandas
- Plotly
- GitHub

## Contenu du projet 
- app.py :génération des graphiques.
- requêtes.sql : requêtes SQL utilisées pour répondre aux questions.
- ventes-par-produit.html: graphique des quantités vendues par produit.
- ventes-par-region.html : graphique des quantités vendues par région.
- chiffre-affaires-par-produit.html: graphique du chiffre d'affaires par produit.

## Résultats obtenus 

Le projet permet :

- de calculer le chiffre d'affaires total;
- de calculer le chiffre d'affaires par produit;
- de calculer le chiffre d'affaires par région;
- de créer des graphiques interactifs avec Python.
